# GeoSea versão 0.1
Plugin para QGIS voltado à navegação e levantamentos hidrográficos, com integração de sensores, posicionamento GNSS, planejamento de linhas e apoio à navegação em tempo real.


GeoSea is a QGIS plugin developed by Mirella F. Marques as part of her Master's research at the Graduate Program in Ocean and Earth Dynamics (PPG-DOT), Universidade Federal Fluminense (UFF).

The project focuses on real-time maritime navigation and hydrographic survey support through GNSS positioning, sensor integration, navigation planning and data processing within QGIS.
